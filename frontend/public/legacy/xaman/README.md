# Capturas del tutorial Multisign (estación Council del Legacy)

El tutorial de `CouncilInXaman.tsx` busca aquí las cuatro capturas reales del flujo en
Xaman. Guarda las imágenes con EXACTAMENTE estos nombres:

1. `multisign-step-1.png` — Xaman → xApps → buscar “Multisign” (resultados de búsqueda)
2. `multisign-step-2.png` — La pantalla **Setup** vacía (Quorum 0 · Add Signer)
3. `multisign-step-3.png` — Miembros añadidos con peso 1 y quórum puesto (antes de Submit)
4. `multisign-step-4.png` — **Review transaction** (tipo Set Signer List, con quórum)

Si falta un archivo, la página enseña un marco-placeholder con el nombre esperado — no
rompe nada. Formato PNG (si usas JPG, cambia la extensión también en `CouncilInXaman.tsx`).

⚠️ Este directorio se sirve TAL CUAL en producción: revisa que las capturas no enseñen
direcciones, nombres o saldos que no quieras publicar, y que la red que aparezca sea la
que toca (una captura hecha en Xahau enseña «Xahau» en la esquina).
